Como obter o Token:
1. Acesse developers.facebook.com → Ferramentas → Explorador de API do Graph
2. Selecione seu App e gere token com permissões: ads_read e ads_management
3. Para uso prolongado: use um System User Token (não expira) ou token de longa duração (60 dias)
4. O Ad Account ID está em Meta Ads Manager → URL da conta (formato act_XXXXXXXXX)
📸 Instagram & Facebook — API Orgânico
Não configurado
Como obter os dados (siga o passo a passo do chat):
1. Gere o token no Graph API Explorer com permissões pages_read_engagement instagram_manage_insights read_insights
2. Troque por token de longa duração (60 dias) via /oauth/access_token?grant_type=fb_exchange_token…
3. Busque o Token de Página permanente via /me/accounts — esse nunca expira
4. O Facebook Page ID vem na mesma resposta do /me/accounts (campo id)
5. O Instagram Business ID via /PAGE_ID?fields=instagram_business_account

Não conectada

4. Configure com colunas: Campanha, Status, Tipo, Impressões, Cliques, CTR, CPC médio, Custo, Conversões, Taxa de conv., Custo/conv., Valor conv. total, ROAS
